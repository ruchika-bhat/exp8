# AIM: STUDY OF FOR LOOP


# THEORY:
The for loop in Python is a control structure used to repeat a block of code multiple times in a simple and organized way.
It is mainly used when we already know how many times the loop should run.
This helps avoid writing the same code again and again.

In this experiment, different programs were implemented to understand how the for loop works in various situations.
# Syntax of For Loop:
The basic syntax of a for loop is for variable in range(start, stop, step):. 
The variable changes its value during each iteration. The range() function generates a sequence of numbers that the loop follows.

# Range() Function:
The range() function can work in three ways: with only a stop value, with start and stop values, or with start, stop, and step values. 
It is important to remember that the stop value is not included in the sequence.

# Working of For Loop:
The working of a for loop is easy to understand. It starts from the given starting value, executes the statements inside the loop,
updates the value based on the step, and continues until it reaches the stopping condition.

# Applications of For Loop:
For loops are commonly used to print numbers, find the sum of natural numbers, generate even or odd numbers, and perform repeated calculations. 
They make tasks faster and more efficient.

# Nested For Loop:
A for loop can also be nested, which means placing one loop inside another. Nested loops are useful for working with patterns, tables, and matrices.
